# GrowthFilm — Mac用 成長記録動画アプリ

複数の写真の両目の位置をそろえて、成長の変化をMP4動画にする日本語Macアプリです。

**この配布物はソースコード版（0.2.0）です。コンパイル済みの.appは同梱していません。Macで下記のビルドを行うとGrowthFilm.appが生成されます。制作環境がLinuxのため、macOSでのビルド・起動・動画出力とGoogleアカウント連携の実動作は未検証です。**

## 1. 最初にアプリを生成する

必要なもの：

- macOS 13 Ventura以降。Apple Silicon／Intelの使用中のMac向けに生成します。
- Xcode 15以降、またはSwift 5.9以降を含むAppleのCommand Line Tools。
- Googleフォトを使う場合だけ、Googleアカウントとネット接続。

手順：

1. ZIPをMacにダウンロードして展開します。
2. 開発ツールがなければ「ターミナル」で `xcode-select --install` を実行し、Appleの案内に従ってインストールします。すでに対応するXcodeがある場合は不要です。
3. `GrowthFilm` フォルダ内の **Build.command** を実行します。
4. テストとコンパイルが終わると `dist/GrowthFilm.app` が生成され、Finderとアプリが開きます。
5. GrowthFilm.appを「アプリケーション」フォルダへドラッグしてください。以降は通常のMacアプリとして起動できます。

Build.commandをダブルクリックして開けない場合は、ターミナルに `bash `（末尾に半角スペース）と入力し、Build.commandをそのウインドウへドラッグしてEnterを押してください。展開後のパスはMacごとに異なるため、手でパスを入力する必要はありません。

ビルドに失敗したら、ターミナルのエラーをコピーして相談してください。依存ライブラリの追加インストールは不要で、Appleの標準フレームワークだけを使用しています。スクリプトはアプリをローカル署名します。Appleによる配布用署名・公証済みアプリではありません。

Xcodeで編集する場合は、`Package.swift` をXcodeで開けます。通常の利用用.app生成にはBuild.commandを使ってください。

## 追加機能：期間全体から最大2,000枚を抽出（0.2.0）

1. まず写真を取り込むか、保存済みのプロジェクトを開きます。
2. 左側の **「期間全体から最大2,000枚を抽出」** を押します。
3. 日付がある対象写真のうち、最大2,000枚が「動画に含める」に設定され、撮影日順に並びます。
4. 要確認の写真は両目を指定してから、プレビュー・書き出しを行ってください。
5. やり直す場合は **「抽出前に戻す」** を押します。

抽出の仕様：

- 現在「動画に含める」がオンの写真を候補にします。手動で対象外にした写真は抽出しません。
- 撮影日時を使って期間の最初から最後までを等間隔に区切り、その時点に近い写真を重複しないよう選びます。単に写真の枚数で等分する方式ではありません。
- 日付のある候補が2,000枚を超える場合は2,000枚、以下なら全候補を選びます。2枚以上選ぶ場合は最初と最後の写真を含めます。
- 写真のない時期があるため、実際の撮影間隔が完全に等間隔になるとは限りません。撮影日がすべて同じ場合は現在の並び順から均等に選びます。
- 撮影日が不明な写真は対象外にし、件数を画面下に表示します。全候補が日付不明の場合は変更せず案内を表示します。必要なら写真の日付を手動で設定して再抽出します。
- 顔の検出結果やピントの良さは抽出条件に含めません。選ばれた写真に両目未指定のものがあれば「要確認」になります。
- 元画像・取り込み済み写真は削除しません。抽出されなかった写真は「動画に含める」をオフにします。
- 「抽出前に戻す」は直前の1回の抽出前の対象設定と並び順を戻します。抽出後に追加した写真は末尾に残り、削除した写真は復活しません。目の位置と日付の編集は維持します。
- 抽出結果はプロジェクトに保存できます。「抽出前に戻す」の履歴自体はアプリ再起動や別プロジェクトを開いた後には残りません。元の選択も残したい場合は抽出前に別名のプロジェクトを保存してください。
- この機能は**アプリに取り込んだ写真**を対象にします。Googleフォトの選択画面の2,000枚制限は変わりません。大量の写真から抽出したい場合はMac内の写真をまとめて読み込んでください。抽出前に全写真の取り込みと目の検出を行うため、枚数によって時間とディスク容量を要します。

更新手順：現在の編集をプロジェクト保存し、アプリを終了してください。新版ZIPを別フォルダに展開してBuild.commandを実行し、新しく生成された.appに置き換えます。Google設定は同じキーチェーン項目を使用します。更新版はMacでのビルド・実動作未確認です。

## 2. Mac内の写真で動画を作る

1. 「写真を追加」からJPEG／HEIC／PNG／TIFFを複数選択します。
2. 撮影日が取得できた写真は日付順、日付不明の写真は後ろに並びます。同日の並びや順番は左側の上下ボタンで変更できます。
3. 1人だけ検出した写真は自動で両目を設定します。複数人の写真や検出できない写真は「要確認」になります。
4. 複数人の写真は、元画像上の番号と「検出した顔を選ぶ」メニューを対応させて対象を指定します。人物を自動で識別・追跡する機能ではありません。
5. 手動修正する場合は「両目を手動で指定」を押し、**写真の左側の目→右側の目**の順にクリックします。2つの目を指定すると反映されます。写真の向き・大きさ・位置だけを変換し、顔の形は変えません。
6. 写真ごとの日付は画面下で修正できます。撮影日不明の写真には、指定するまで日付を重ねません。
7. 縦／横、1枚の表示時間、顔の大きさ、目の高さ、切替効果、日付表示を調整します。
8. 「連続プレビュー」で確認し、「MP4を書き出す」で保存します。

未確認の写真が含まれている場合は書き出しを止めます。両目を指定するか、その写真の「動画に含める」を外してください。

出力はH.264 MP4、縦1080×1920／横1920×1080、30fps、音声なしです。切り替え効果は前の写真との短いクロスフェードで、顔を変形するモーフィングではありません。BGM追加や年齢の自動計算はこの版には含めていません。

## 3. Googleフォトを設定する（初回のみ）

Googleの認証設定は利用者のアカウントで作成します。アプリ内に共通のクライアントIDやパスワードは埋め込んでいません。

1. [Google Cloud Console](https://console.cloud.google.com/) を開き、プロジェクトを作成または選択します。
2. APIライブラリで **Google Photos Picker API**（photospicker.googleapis.com）を検索して有効化します。Google Photos Library APIとは別です。
3. Google Auth Platformでアプリ名・サポートメール等の必須項目を設定します。個人用の外部アプリとしてテストする場合は、Audience／対象に自分のGoogleアカウントを「テストユーザー」として登録します。
4. Data Access／データアクセスで次のスコープを設定します：

   `https://www.googleapis.com/auth/photospicker.mediaitems.readonly`

5. Clients／クライアントでOAuthクライアントを作成し、アプリケーションの種類は **デスクトップアプリ** を選びます。WebアプリやAPIキーは使いません。
6. クライアントのJSONをダウンロードします。
7. GrowthFilm右上の「…」→「Google設定」→「OAuth JSONを読み込む」でそのファイルを選びます。
8. 「Googleフォト」を押します。標準ブラウザでGoogleへのログインとアクセス許可を完了します。
9. 開いた写真選択画面で使う写真を選び、「完了」を押します。アプリがダウンロードと目の検出を開始します。

認証JSONやトークンをチャットへ貼り付ける必要はありません。設定はMacのキーチェーンに保存します。アクセストークンと更新トークンはアプリ起動中のメモリだけに保持するため、再起動後はGoogle認証の操作が再び必要です。

Googleフォト側にアルバムの表示・検索が用意されていれば、その画面で目的の写真を選べます。アプリが既存アルバム名やURLを直接指定して自動取得する方式ではありません。選択画面はGoogleの管理下にあるため、画面内の操作は提供状況に従います。追加の写真を取り込むときは再度「Googleフォト」を押してください。同じ写真を再度選ぶと重複して追加されます。

- 403：APIの有効化、テストユーザー、対象アカウント、アクセス許可を確認します。
- ログイン拒否：デスクトップ用JSONか、組織アカウントの制限がないかを確認します。
- 時間切れ／中止：もう一度「Googleフォト」から開始します。
- 動画だけ選択：静止画を選び直します。
- 認証設定の削除：「Google設定」→「設定を削除」。Google側の許可も取り消す場合は[Googleアカウントの接続管理](https://myaccount.google.com/connections)を使用します。

一般配布する場合は、自分専用のテスト設定とは別にGoogleのOAuth公開・審査条件を確認してください。

## 4. 作業を保存して再開する

「…」→「プロジェクトを保存」（Command-S）で `.growthfilm` を保存します。写真の作業コピーと両目の座標、順番、日付、動画設定がまとまります。「…」→「プロジェクトを開く」で再開します。

このファイルはフォルダ形式のパッケージです。内部の `Photos` と `project.json` を分離せず、全体を移動・バックアップしてください。保存していない編集は終了時に失われます。Googleの認証情報はプロジェクトに含めません。

## 写真の扱いと仕上がり

- 顔検出と動画作成はMac内で処理します。顔認識サービスや生成AIへの写真送信はありません。
- 元写真は上書きしません。処理用コピーは向きを正規化したJPEG（最長辺4096px、品質0.95）に変換します。元ファイルと同一の保存やHDR維持を目的としたアプリではありません。
- Googleからは選択した写真を取得し、取得後にPickerセッションを削除します。通信中止時にも削除を試みます。ネット断で削除できなければGoogle側の有効期限に従います。
- 一時コピーは終了時に削除します。アプリが強制終了した場合はmacOSの一時領域に残ることがあります。プロジェクトとして保存した写真は利用者の保存先に残ります。
- 全写真の目を同じ座標に置くため、周辺が切れたり、画像のない領域が暗い余白になったりします。「顔の大きさ」「目の高さ」で調整してください。
- 横顔、目を閉じた写真、顔が小さい写真、強いブレは手動指定が必要になり、完全に正面を向いたようには補正できません。
- プレビューは低解像度で、その場で写真を読み込むため大量の写真や短い表示時間では遅延することがあります。書き出した動画は指定の30fpsで保存します。

## 開発者向け

- `Sources/AlignmentCore`：両目を固定座標へ移す相似変換。回転＋一様な拡大縮小＋平行移動。
- `Sources/GrowthFilm/PhotoEngine.swift`：ImageIOの向き正規化、Visionの目検出、Core Image描画、AVAssetWriter動画保存。
- `GooglePhotos.swift`：デスクトップOAuth認可コード＋PKCE S256＋state検証、127.0.0.1の一時ポート、Pickerのセッション作成・待機・ページング・Bearer付き画像取得・後片付け。
- `StudioModel.swift`：インポート、編集状態、プレビュー、プロジェクトと動画の保存。
- `GrowthFilmApp.swift`：日本語SwiftUI画面。
- `Tests/AlignmentCoreTests`：両目の座標一致、左右の順番、縮尺の一様性、重複点の拒否、および時系列抽出（上限2,000、連写偏り、日時重複、欠損、端点の維持）。

ビルドはSwift 5言語モード（Package.swiftのtools-version 5.9）を使用します。App Sandboxを有効化していない個人用ビルドです。App Store向けにする場合はファイルアクセス権・ブックマーク・ネットワーク権限を含む別途の対応が必要です。

## 検証の状況

ソース作成環境で確認済み：全Swiftファイルの構文解析、Build.commandのシェル構文、Info.plistの構造、ZIP内容。macOS SDKがないため、型チェック・リンク・XCTest・UI・Vision・AVFoundation・実アカウントOAuthは未実行です。構文解析の成功はビルド成功を保証しません。

Macでの最初の確認：

1. Build.commandでテストとビルドが成功すること。
2. 向きの異なる写真3枚を読み込み、検出または両目のクリックで位置がそろうこと。
3. 複数人の写真で番号と対象の顔が一致すること。
4. 縦・横のMP4をQuickTime Playerで開き、上下の向き、目の位置、長さ、切替、日付を確認すること。
5. プロジェクトを保存・終了・再開して、写真と編集内容が一致すること。
6. OAuth設定後に写真を選択して取り込めること、ログイン拒否・選択中止後に再試行できること。
